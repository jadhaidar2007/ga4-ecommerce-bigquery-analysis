## Application form: project description (3–4 sentences)

I built an end-to-end analytics project on the Google Merchandise Store GA4 sample dataset in BigQuery, analysing 92 days of event-level data to understand traffic, conversion and revenue. Using SQL with nested-data handling, window functions and cost-aware wildcard queries, I produced daily KPIs, a session-based purchase funnel, channel and product performance, and audience breakdowns. I turned the results into a four-page Looker Studio dashboard and a set of recommendations to improve conversion. The full code, documentation and dashboard are on my GitHub: github.com/jadhaidar2007/ga4-ecommerce-bigquery-analysis.

# G. CV bullets and application text

## CV bullets (project entry)

**GA4 Ecommerce Analytics | BigQuery, SQL, JavaScript (Chart.js)** · github.com/jadhaidar2007/ga4-ecommerce-bigquery-analysis

- Wrote 6 BigQuery Standard SQL queries over 92 days of GA4 event data (nested `event_params` and `items` flattened with `UNNEST`), covering daily KPIs, acquisition, funnel, products, new vs returning users and device/country, with `_TABLE_SUFFIX` filters to stay within sandbox limits.
- Built a session-based funnel (view_item → add_to_cart → begin_checkout → purchase) using window functions to quantify step-to-step drop-off and identify the biggest conversion leak.
- Built a four-section web dashboard on pre-aggregated BigQuery tables, hosted on GitHub Pages, and wrote 5 data-backed recommendations for conversion, retention and paid search.

Optional add-on you can verify on the dashboard: "…found that 80% of product-view sessions never reach add-to-cart."

## Application form: project description (3–4 sentences)

I built an end-to-end analytics project on the Google Merchandise Store GA4 sample dataset in BigQuery, analysing 92 days of event-level data to understand traffic, conversion and revenue. Using SQL with nested-data handling, window functions and cost-aware wildcard queries, I produced daily KPIs, a session-based purchase funnel, channel and product performance, and audience breakdowns. I turned the results into a hosted dashboard and a set of recommendations to improve conversion. The full code, documentation and dashboard are on my GitHub: github.com/jadhaidar2007/ga4-ecommerce-bigquery-analysis.
